# VAGON Restoran BW — Website

Static restaurant website concept built for Belgrade Waterfront. Deploy on Vercel with Framework Preset **Other** and root directory `./`.

> **Media note:** The HTML currently refers to `assets/` photographs, menu scans, and a promotional video from the design package. These media files have **not yet been uploaded to this repository**. Before public presentation, add approved originals to the `assets` folder, verify the phone number, and confirm menu prices and rights to publish imagery.
